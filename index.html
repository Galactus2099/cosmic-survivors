PROJECT NOTES

Built for your vision

A lightweight offline playable preview plus an optional add-on for the original PokéSurvivor source.

In this demo

Choose one of five supplied character artworks, equip eight visually distinct looks, survive enemy waves, collect XP, choose upgrades, fight a boss and save records locally.

For the upstream game

The mods/ folder includes an overlay that applies cosmetic skins to animated sprite sheets in the MIT-era PokéSurvivor engine. See README for integration steps.
