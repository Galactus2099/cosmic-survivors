# Cosmic Survivors Classic — noncommercial fan test

Based on PokéSurvivor by JPTER78, immutable MIT-era revision b29708900da26b34e70d2dc07ad1659a719f4a78 (October 14, 2026).

Original copyright and MIT engine terms are in LICENSE; SpriteCollab artist attributions are in CREDITS.md. Third-party sprites have CC BY-NC 4.0 licensing and Pokémon characters/trademarks belong to their respective owners. This is a noncommercial unofficial fan prototype.

Original game systems are maintained. Account backend and online multiplayer are not connected to the original author; create a local account for local-only saved progress.

Open /classic/ to play. Use the Cosmic Wardrobe button to equip Shadow, Gold, Prismatic, Galaxy and Crimson Nebula visual filters, earn Spirit Lanterns for 25 enemy defeats, and try experimental Mega Mode (stat bonuses and aura, not yet species-specific Mega sprites).

Changes remain isolated from Nightfall and the current Cosmic Survivors homepage.
